BALLON CHASSEUR

Ta famille. Tes pouvoirs. À toi de jouer !

CHOISIS TON DÉFI

Options du jeu

Automatique : tu suis le ballon. Fixe : tu gardes ton joueur. Tu contrôles aussi les extérieurs quand ils ont le ballon. Change avec 1, 2, 3 ou LB / RB.

Comment jouer ?

Lance la balle sur les trois joueurs de l'autre famille jusqu'à ce qu'ils n'aient plus de points de vie. Charge tes lancers, attrape leurs balles, saute, cours… et sors ton pouvoir !

Les quinze pouvoirs

Toute la famille

Survole un personnage pour le voir saluer. Les réglages servent à faire des images : choisis la pose, le décor (ou aucun pour un fond transparent) et télécharge.

PAUSE

Flèches : bouger (deux fois vers l'avant = course) · X : lancer (tenu = charge, ⬆ ou ⬇ = diagonale) ou sauter · C : sauter avec la balle, passer (direction + C) ou attraper · V : pouvoir · 1 2 3 : choisir son joueur · Clic sur un ennemi : cibler, maintenir pour charger, relâcher pour lancer · Clic droit : annuler la charge · T / clic stick droit : cible suivante en visée automatique

Personnage fixe : change toi-même avec 1, 2, 3 ou LB / RB, même après un K.-O. Tes coéquipiers jouent seuls, sauf les extérieurs avec le ballon : tu prends alors le contrôle.
